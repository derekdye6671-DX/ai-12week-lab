## 4. 冒险岛的技术要点（给新对话省时间）

- 网页：纯 HTML / JS 单文件 `index.html`；数据存在用户手机的 localStorage，键 `quest-island-v1`（字段 log、wk、ex、sub、pro、pr）。
- `plan.json`：计划源，字段 version、WEEKS、CC、GIT、GPT、GEM、GROK、DAYS、EXTRA、PRODUCT。现在版本 v2.2-2026-11-16。
- `verified.json`：`{updatedAt, items:{键:{status, reply, at}}}`；键：`d_<日期>`（每日）、`w<周>_<quest|git|m_gpt|m_gem|m_grok>`（周任务）、`x_<E编号>`（拓展）。改 AI 关结构时要保证第 1–2 周已验收的旧键还能正常显示。
- `sw.js`：plan.json、verified.json 和页面走网络优先；拿不到时用缓存，并带 `x-quest-stale: 1` 响应头，页面会提示「验收清单可能不是最新」。
- 金币：XP = 累计获得；金币 = 获得 − 花费。现在全部做完约 15,360，付费造型合计 12,800。衣橱 l1–l12 按周开放，l13 晨练 30 天、l14 英语 30 天、l15 拓展验收 5 个、l16 隐藏（集齐 8 张图鉴）。
- 产品优先：PRODUCT 里的 P 项做完一项，网页会问是否提前下一项；产品没做完前，未验收的非产品拓展任务隐藏。
- 提交：`git -c user.name=Claude -c user.email=noreply@anthropic.com commit`，推送用 `git -c push.negotiate=true push origin main`，提交说明末尾加 Co-Authored-By 和 Claude-Session 两行。
