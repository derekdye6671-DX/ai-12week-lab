## 5. 风险和我做不到的事

1. **静态快照机制（不会自动同步）**：方式一每次通过 `Import code` 导入仓库都只是“当前时刻的快照”。当 Claude Code 更新了仓库代码或文档后，我不会自动感知，必须由用户新开一个对话重新点一次导入；同时我无法直接修改本地文件或发起 PR。
2. **图像中的精细中文字体渲染偶有瑕疵**：生成带文字的封面图时，遇到笔画复杂的生僻字或大段小字，偶尔会出现笔画粘连或错别字。**应对方式**：我负责生成高质量底图和超大主标题，细小的副标题和角标建议导入剪映或醒图用标准中文字体叠加，成片效果最稳。
3. **不占用本地算力**：所有图像生成与多模态分析均在云端完成，不会让用户在旧公司电脑上安装任何需要独立显卡的本地模型或命令行工具。
4. **联网信源颗粒度边界**：虽然支持联网搜索，但在做小红书最新违禁词库、平台最新商单规则等需要“逐条附带官方公告链接”的严谨调研时，以 **Perplexity** 的检索底稿为准，我负责将规则转化为视觉避坑和排版建议。
