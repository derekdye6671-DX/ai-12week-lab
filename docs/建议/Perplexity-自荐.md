**按 5.4 节，已经分给我的任务我都能做**：第 3 周（B站 5 位同类 UP 主）、第 4 周（B站 / 抖音 AI 内容标注和原创规则）、第 5 周（5 个目标规划产品的新用户开局）、第 6 周（YouTube 新频道起步）、第 7 周（竞品表 + 合规要求）、第 9 周（模型 API 价格）、第 10 周（小红书同类产品价格区间）、第 11、12 周（小红书上架规则核对）。

**建议额外交给我的（需用户和 Claude 决定）**：

- 📦 P1 小红书数字产品调研（第 3 周）：我负责「卖什么、卖多少钱、怎么卖」里能公开查到、可附出处的部分。小红书站内笔记需要登录才能看全，这部分建议用户手机上截图或复制给我，由我整理核对。
- 🐙 「本周认识一款 GitHub 工具」：Claude 每周一给候选，我可以补上每个候选的官网 / 仓库链接、Star 数、最近更新时间、适不适合零基础，帮用户挑。不替代 Claude 出候选。
- 🔎 事实核查：其他 AI 写进仓库的数字、价格、平台规则，我按「已核实 / 有出入 / 查不到」标一遍。
- 🎬 第 5、9 周的视频复盘：B站公开页面上的播放、点赞等数字我可以帮着记录；完播率等后台数据只有用户能看到，需要用户截图。

**我做不好、建议交给别人的**：

- 封面、横幅、结构图等视觉 → Gemini。
- 每日英语对话陪练、口播稿和标题 → ChatGPT。
- 写代码、改冒险岛、验收打卡 → Claude / Claude Code；代码检查 → Codex。

## 3. 我为用户设计的 12 周训练计划（第 3–12 周）

目标：让用户学会**像产品经理一样做调研**——问对问题、判断来源靠不靠谱、把结论变成决定。每周 1–2 小时，全部贴合 5.4 节的主题。

| 周 | 用户要跟我练什么 | 交付物 | 怎么验收 |
| --- | --- | --- | --- |
| 3 | 把一个模糊问题拆成可查的小问题（用 P1 和「5 位 UP 主」练） | ① B站 5 位同类 UP 主对比表（选题、时长、更新频率、出处）；② P1 调研笔记 | 用户随机点开 3 个出处链接，能对上表里的说法；能用一句话说出「我的第 1 条视频选哪个题、为什么」 |
| 4 | 读规则原文，区分「平台明确要求」和「网上的说法」 | B站 / 抖音 AI 生成内容标注、原创声明规则清单，每条注明出自哪份官方文件 | 用户能说出发第 1 条视频时必须做的标注动作；第 1 条视频按清单发布 |
| 5 | 竞品拆解：看别人怎么做新用户开局 | 5 个目标规划产品的开局流程对比（步骤、问了什么、截图或链接） | 用户从中挑出 2 个做法用到 P2 前置页面，并说出理由 |
| 6 | 判断建议的可信度：官方帮助中心 vs 博主经验 | YouTube 新频道起步清单 + 中文 AI 频道常见栏目，标明哪些来自 YouTube 官方 | 用户按清单把频道开好；能指出 1 条「博主说法但官方没写」的建议 |
| 7 | 做一张能拿来做决定的竞品表 + 合规入门（明白了解档） | 计划打卡类竞品表（≥5 个：价格、功能、卖点、差评）+ 个人信息和 AI 服务合规清单（每条附法规原文链接） | 用户能说出自己产品的 1 个差异点；合规清单出 5 道判断题，答对 4 道 |
| 8 | 节日周不安排 | — | — |
| 9 | 看懂 API 价格表（为第 10 周的密钥和费用铁律做准备） | 主流模型 API 价格和接入方式对比表（按「每 1000 次评估大约多少钱」换算） | 用户能估算 10 份测试记录大约花多少钱；测试题 3 道答对 3 道 |
| 10 | 用数据定价 | 小红书同类数字产品价格区间（样本数、最低 / 中位 / 最高、出处） | 用户给出 v1 的定价并能用表里的数字解释 |
| 11 | 上架前核对规则 | 小红书卖数字产品的上架规则清单（资质、类目、禁止事项、出处） | 用户逐条打勾，标出还没满足的项 |
| 12 | 上架前最后核对 + 复盘调研方法 | 最终核对表（规则有没有变化）+ 「我的调研方法」一页纸 | 规则无遗漏；用户能独立写出下一次调研的 5 个问题 |

## 5. 风险和我做不到的事

- 查不到的就是查不到：需要登录、付费墙、平台后台的数据我拿不全，会标「未查到」，不估算、不编造。
- 数字会过期：播放量、价格、平台规则以查询当天为准，上架前（第 11、12 周）要再核对一次。
- 合规内容只到「明白了解」档：我能找到法规原文和要点，但不能替代律师意见；真正要备案或办资质时需要找专业人士确认。
- 积分消耗：大型调研比较耗积分，我无法提前准确估算。
- X（推特）内容覆盖不全，热点和用户声音以 Grok 为准。
- 不碰用户本地文件，不改 `PLAN.md` / `DECISIONS.md` / main，不提交任何密钥和隐私数据。
